# Indicator Template Guide

Use the template file in `/templates/indicator-template.pine` when starting a new Pine indicator.

## Minimum Requirements

A proper indicator should include:
- full title
- short title
- version note in comments
- type and status in comments
- summary comment
- clear section separators
- no random dead code left behind

---

## Recommended Sections

1. Header comments
2. Indicator declaration
3. Inputs
4. Core calculations
5. Conditions
6. Plotting
7. Alerts
8. Notes / TODO

Consistency beats clever chaos.
