# Naming Conventions

## Goals
Naming must support:
- discoverability
- version clarity
- archive safety
- future scalability

---

## File Naming Pattern

`Script-Name_vMajor.Minor.pine`

### Good Examples
- `Smart-Money-Pro_v2.0.pine`
- `EGX-Scalping-Pro_v1.5.pine`
- `Volume-Pressure_v0.8.pine`

### Bad Examples
- `script1.pine`
- `newscript.pine`
- `final_final.pine`
- `lastversion_real.pine`

---

## Folder Naming Pattern

Use kebab-case or readable title folders consistently.

### Good
- `smart-money`
- `trend-tools`
- `volume-analysis`

### Avoid
- `miscstuff`
- `new folder`
- `temp123`

---

## Version Naming

- `v0.x` = early / experimental
- `v1.x` = stable production baseline
- `v2.x` = major rewrite / architecture evolution
