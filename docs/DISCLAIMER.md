# Disclaimer

This repository contains technical-analysis tools, TradingView Pine Script indicators, and backtesting strategy prototypes created for research, education, and portfolio demonstration purposes.

## No Investment Advice

The scripts in this repository do not provide financial, investment, trading, legal, tax, or brokerage advice. Any signals, dashboards, alerts, levels, or strategy results are analytical outputs only and should not be treated as buy, sell, or hold recommendations.

## No Performance Guarantee

Past chart behavior, backtest output, or indicator signals do not guarantee future performance. Markets can move differently from historical patterns, and technical-analysis models can fail.

## Use at Your Own Risk

Anyone using these scripts should independently validate the logic, test across multiple symbols and timeframes, and apply proper risk management before using any result in a trading workflow.

## Experimental Tools

Scripts marked as `Experimental`, `Legacy`, or `Incomplete / Broken` should not be treated as production-ready tools.

## AI Naming Note

Some files may use `AI` in the project name. Unless explicitly documented otherwise, current Pine Script logic is rule-based and not machine-learning based. AI-assisted reporting, automation, and scoring are planned future extensions.
