# Smart EGX Institutional Suite

## Overview
A legacy multi-factor EGX indicator that combined moving averages, RSI, ADX, volume analysis, market structure, stop-hunt logic, order-block-style conditions, and a trend dashboard.

## Type
Indicator

## Status
Archived

## Version
v5.0

## Purpose
This script appears to represent an older broad-suite attempt to combine multiple trend and smart-money-inspired signals into a single chart overlay.

## Main Logic
- plots EMA 13, 30, 72, and 144
- computes RSI and ADX
- detects volume spikes
- tracks simple pivot-based BOS conditions
- flags simple stop-hunt conditions
- flags simplified order block conditions
- builds a trend and score dashboard

## Outputs / Chart Behavior
- moving average overlays
- BOS shapes
- stop-hunt markers
- order-block markers
- dashboard and legend

## Archive Reason
Archived because newer repository scripts provide more focused logic, clearer categorization, and better maintainability.
This script is retained for lineage and reference, not as an active mainline tool.

## Notes
The archived repository copy is intentionally preserved as a legacy reference point within the EGX family tree.
