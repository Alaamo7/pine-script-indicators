# Smart Trend Dashboard – EGX Pro v0.9

**Status:** Legacy Reference  
**Category:** Archive / Legacy / Trend Dashboard  
**Platform:** TradingView Pine Script v5

## Purpose

Smart Trend Dashboard – EGX Pro v0.9 is preserved as a legacy reference for an older dashboard-style trend indicator. It combines price action, OBV, ROC momentum, DI/ADX, RSI, and MACD into a compact table.

## Why Archived?

This script is kept under `archive/legacy` because newer repository indicators now cover trend, momentum, liquidity, and dashboards in cleaner Pine v6 implementations.

## Core Features

- Price action state.
- OBV trend check.
- ROC momentum state.
- DI/ADX strength.
- RSI state.
- MACD trend state.
- Buy/sell markers.
- Compact dashboard and legend.

## Caution

This is a Pine v5 legacy script and should not be considered the preferred production trend dashboard. Use it for historical reference or comparison only.
